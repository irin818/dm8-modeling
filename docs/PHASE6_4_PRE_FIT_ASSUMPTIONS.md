# Phase 6.4 拟合前事实与假设冻结

本文件在 Phase 6.4 的任何模型拟合和结果读取之前写入。输入基线为 Phase 6.3 commit `9aae8b2ef3be906af81d814029269ac7eb4e00e7`。以下事实不可因本阶段模型结果而修改。五只 fly 是生物重复单位；ROI 与 null 重复均不是额外生物样本。

## Phase 6.3 已知事实

1. 五只 fly 的中心区带符号均值全为负：fly1 −0.001253、fly2 −0.002691、fly3 −0.001826、fly4 −0.003952、fly5 −0.003825；等 fly 权重群体值 −0.002709。
2. 五只 fly 的中心时间轨迹最强均在 bin 1。
3. 1000 次完整 RF 重算且重新定位中心的时间错位 null 中，群体负中心比所有 null 更负。这只是 stimulus-linked 的内部探索性证据，不能排除同步伪影。
4. 去掉 fly4 后，中心区仍为负（约 −0.002399）。
5. `CENTER_ESTIMATED` 子集的群体负中心更强（−0.005011）；该标签来自同一数据，属于敏感性分析。
6. 固定 3–6 px 环绕区在 fly1、fly5 为正，在 fly2、fly4 为负，在 fly3 接近零且时间上混合。群体值约 −0.000114。
7. 稳定中心子集没有恢复统一的正环绕：仍仅 fly1、fly5 为正。
8. 4 个时间 bin 中没有一个在五只 fly 中共享正环绕。
9. 当前已知的可靠形状是 **center = CONSERVED；periphery = HETEROGENEOUS**。
10. 因而 Li et al. 2021 的完整负中心／正环绕结构尚未在当前数据中复现。

**POTENTIAL GLOBAL DESIGN ISSUE：**旋转后的一维相邻点并非独立测量，且 ±x 可能高度相关。常规 AICc/BIC 的独立同方差误差假设可能乐观。本阶段把这些信息准则作为同一表征下的描述性比较，不把其阈值当生物机制的检验；留一 fly 泛化、五只 fly 一致性和 Phase 6.3 null 是必需的独立诊断。

原始数据、Phase 6.3 RF、center、ROI 筛选、10 s Gaussian、4×10 时间核与所有既有结果均只读。宽度、幅度及 baseline 的数值约束将在首次拟合之前写入 `configs/phase6_4_dog_test.json`，此后不依据结果调整。

## Li 2021 方法核对与本轮冻结的实现

本地论文 PDF 第 7–8 页 Figure 4 与第 22–23 页 STAR Methods / Quantification and Statistical Analysis 已在拟合前检查。

**SOURCE_DEFINED：**个体时空 RF 标准化并中心对齐，群体平均 2D RF；平均 2D 图旋转一整圈共 1000 步，每步投影为 1D 再平均；最终拟合 DoG。论文为防弱环绕使宽度无界增长而设环绕宽度上界。论文 Figure 4 另有独立 moving-bar 定位、物理视角单位和经过校正的 GCaMP 数据；当前数据不具备这些等价条件。

**IMPLEMENTATION_ASSUMPTION：**论文文字未唯一规定插值、外部边界、缺失值与投影归一化。本轮在 15×15 已冻结有符号 RF 上做 1000 个均匀角度（0° 至小于 360°），围绕中心双线性取样；网格外及 NaN 保持缺失，投影沿一轴对有效像素取均值，最后逐位置平均。使用 −7…7 px 的 15 个横向位置。现有 `radial_profile()` 用环带均值，定义不同，仅作预定敏感性。1D 点有关联，AICc 是条件化、描述性的模型比较。

**数值约束理由：**网格中心到轴向边缘仅 7 px；窄于半像素的宽度分辨不了，宽于 7 px 的环绕会与基线难以区分。因此中心 σ 固定搜索 0.5–4 px，第二尺度 σ 固定搜索 1–7 px，步长 0.25 px，两尺度至少差 0.25 px。三个幅度范围的绝对值上限 0.1、基线绝对值上限 0.05，宽于已冻结 RF 的观测幅度（包含稳定子集极值约 0.0604）；这些是防止强抵消退化的数值约束，不是生物先验。M1 与 M2/M3 的第一宽度共用同一网格；M3 的符号约束是定义，正幅度本身不是证据。配置已在首次拟合前固定，后续任何边界命中只报告，不调参。
