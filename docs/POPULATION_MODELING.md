# 从单 ROI 到五只 fly 的共享模型

## 问题与评价口径

目标是检验五只 fly 对**同一**冻结数字刺激是否存在可复用的视觉编码核。5 是生物重复数；236 个 ROI 是嵌套观测。主评价使用同一 40 更新因果特征、同一全局时间切分、每 ROI 训练段标准化的原始强度、每 ROI 测试集 Pearson r / R² / MSE / 训练方差归一 MSE。比较时报告所有 ROI、训练定义的响应 ROI、每 fly 中位数及相对于对应单 fly Ridge 的 ΔR²。R² < 0 表示比使用测试段目标均值作常数预测还差。

## 模型梯度

| 方法 | 数学形式与假设 | 主要参数 | 优点与局限 |
|---|---|---|---|
| 单 fly 像素 | 每 ROI 用训练段选一个空间位置，拟合 4 个时间箱 | 236×4 个斜率及位置、截距 | 清楚易讲；只能抓单位置 |
| 单 fly Ridge | `y_fr = b_fr + X β_fr`；每 ROI 独立 | 236×900 个斜率及截距 | 灵活；参数多且不能跨 fly 迁移 |
| 完全共享 STRF | `y_fr = b_fr + g_fr (X K)`；一核、ROI 各自增益偏置 | 900 + 2×236 | 最直接的共享计算假设；若各 fly/ROI RF 不同会欠拟合 |
| 分层 STRF | `y_fr = b_fr + g_fr X(K + δ_f)`；每 fly 一个收缩偏差 | 900 + 5×900 + 2×236 | 允许 fly 差异；5 只 fly 不足以无限制扩展偏差 |
| 共享低秩基 | 训练段独立 Ridge 核 SVD 后，每个方向分成时间×空间 rank-one 基，再由 ROI 混合 | 约 Q×(4+225) 个基自由度 + Q×236 个 head + 236 截距，Q=1..4 | 可解释的共享时空成分；训练核噪声会传播，rank-one 约束过强时欠拟合 |
| 群体平均 | 每 fly 训练定义响应 ROI 的标准化均值，拟合跨 fly 共享 Ridge | 900 + 1 | 可降低独立 ROI 噪声；目标是群体均值，**不能**同 ROI 预测 R² 直接排序 |
| 共享神经网络 | 尚未进入 | 未设定 | 只有线性共享模型跨折稳定改善时才值得增加复杂度 |

单 fly 与共享模型全部在验证段选惩罚并重拟合训练+验证，再计算测试。共享核可按每 fly 等权或每 ROI 等权；原始强度单位与训练标准化有单独对照。共享低秩方向和 STRF 的符号可与 ROI gain 同时翻转，比较跨折方向时用绝对余弦。

## 跨 fly 迁移

Leave-one-fly-out 每次以其他 4 只 fly 学共享核与正则参数。零样本仅用源 fly 的中位增益/偏置；少量样本只用目标 fly 训练区间最前 20% 成像帧估计目标 ROI 增益/偏置，核保持冻结。测试段不参与适配。目标 fly 的训练段均值/标准差只定义输出单位；所以“零样本”是**零目标监督拟合**，并非连目标强度尺度都不知道的部署场景。5 次迁移结果是有相关性的同一刺激任务，不能当作独立外部刺激泛化。

## 当前结果与选择

两折原始响应单 fly Ridge 测试 R² 中位数为 −0.103、−0.214；完全共享为 −0.174、−0.234；分层为 −0.178、−0.230；共享低秩为 −0.136、−0.214。原始响应的多 fly 参数共享没有稳定改善。验证选出的因果块中位数残差作为**另一个目标表示**时，单 fly Ridge 测试 R² 为 −0.050、−0.021，共享为 −0.088、−0.022，仍未提供共享优于独立的证据。群体均值预测也弱。精确每 ROI/每 fly 结果与跨折核方向稳定性见 `outputs/experiments/phase5_first_round/` 的 CSV/JSON；综合解释见 [最终预测模型报告](FINAL_PREDICTIVE_MODEL_REPORT.md)。

因此当前采用停止条件 B：保存最可讲解的单 fly 基线和共享模型作为对照，不增加共享 CNN/TCN。结论仅适用于当前刺激、当前原始 ROI 强度与时间对齐假设。负结果不能证明 Dm8 生理上没有共享计算。
