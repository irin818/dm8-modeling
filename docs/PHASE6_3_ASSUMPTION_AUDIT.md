## 方法学问题与最小修正

**POTENTIAL GLOBAL DESIGN ISSUE：时间错位的可交换性。** circular shift 保留同 fly 全体 ROI 的共同波动，但不能保证漂移、边界、非平稳记录在所有平移位置都可交换，也不能区分神经视觉信号与刺激同步的成像/设备伪影。固定最小 circular 距离 60 秒，远大于 40 更新历史及 Gaussian 3σ边界；保存全部偏移与零分布，用 `EXPLORATORY INTERNAL VALIDATION` 标记，绝不宣称确认性因果检验。

**说明/实现不一致：**Phase 6.2 配置的 `per_roi_full_payload_standard_deviation` 标签不精确：实际代码在 `[eligible RF frame,ROI]` 的 8084 帧上对 Li-style/raw 定尺度；Gaussian 基线仍在完整 8119 帧 payload 上计算。本轮沿用实际算法并修正说明，避免以改算法换取结果。完整观测结果必须与基线保存图在数值容差内一致。

## 零模型与统计定义（运行前固定）

- 1000 次，seed `6320260930`，每次每 fly 从允许的 raw payload 帧偏移中独立均匀抽样（有放回）；同 fly 所有 ROI 使用同一偏移。
- 原始 trace 的非有限/零比例/常量技术检查在平移前后不变；Li-style 常量及中心数值失败在每次重新评估。先完成各 fly 再合成 population，丢失中心留作 missing，不补零。记录有效 ROI/fly 贡献数。
- 主指标是预定中心区（r≤1.5 px）带符号均值的负尾经验 p：`(1 + #null<=observed)/(1000+1)`；五 fly 加 population 六个主 p 附 BH6，作为探索性参考。
- 中心像素另报负尾；中心区最大绝对值报上尾；径向曲线逐 bin 负尾/双侧 p 为**未调整诊断**，不据此挑 ring。记录 null 2.5/50/97.5 分位数。
- 报告每次 null 的负中心 fly 数，以及 5/5 出现频率；该频率直接从独立偏移的五 fly 联合零分布计算，不假设二项式公平符号。
- STABLE/UNCERTAIN 直接沿用 Phase 6.2 前后半中心距离≤2/>2 px 标签；两组都是同数据定义的描述性敏感性，不当独立验证或因果定位误差实验。
- 外周径向 peak 固定考察 lower edge≥2 px 的已有径向箱，报告正/负最大值与半径；不更改主 3–6 px 环绕区。

## 运行后复查

| 运行前问题 | 运行后发现 / 判定 |
|---|---|
| 聚合隐藏异质性 | 是：主环绕反号抵消 47.3%，5/5 同号仅集中于部分中心像素；外围大多数像素混合。报告全部 fly 值、range、SD 与共识图。 |
| 标准化制造统一图形 | 正尺度本身不翻转符号；raw 既有诊断保留负中心，本轮完整 null 亦重算尺度。单位方差权重仍改变 ROI 贡献，尚无正式校正钙信号。 |
| 同数据定位 | 1000 次每 fly 重新拟合中心；观测中心区五 fly 各自在负尾，population 比全部 1000 次 null 更负。支持刺激对应的内部探索性证据，不能排除同步伪影。 |
| 生物单位 | 图与 null 均先独立 fly、后等 fly 权重，n=5。stable/uncertain 都有五 fly，未将 228 ROI 或 1000 null 当动物数。 |
| 单 fly 驱动 | fly4 对背景/环绕影响最大；去掉它中心区仍 −0.002399，bin1 优势保持。继续保留 fly4。 |
| 单预处理驱动 | 主方法固定 Li-style，raw 诊断沿用 Phase 6.2；没有为每 fly 调 sigma 或择优变换。本轮没有增加 raw null，因此 Level 3 明确针对指定 Li-style 流程。 |
| 时间平均抵消 | 5/5 中心最强 bin1，各箱中心均负；fly3 环绕时间抵消 74.1%、fly5 14.6%，但无统一正环绕箱。 |
| 分析复杂度 | 只用原 4 箱、原 zones 与原中心阈值；外周峰与逐径向 p 明确是未调整描述/诊断，没有按 peak 重定义主 zone、没有 DoG。 |
| 更简单的证据 | 总表、五 fly 值、轨迹及完整 null 已回答核心问题；稳定子集中心 5/5 增强而环绕不统一，定位误差不是环绕缺失的充分解释。 |
| 下一步价值 | 本批记录的可支持结论已接近上限；独立定位、真实神经/伪影区别和可靠环绕需要新证据。按照任务结束条件，6.3 完成即停止。 |

核验结果：观测图逐 fly 匹配 Phase 6.2，旧 manifest 前后通过；本轮两个来源目录共 4949 文件的 SHA-256 清单一致。固定 config 与统计核心的运行前哈希保持不变。视觉检查后仅调整图 9 三组曲线共用纵轴、澄清时间箱文字；图重新渲染并刷新 manifest，null/观测数值没有重跑或修改。运行前哈希记录保存的是审计的运行前版本，因此本节追加后文档自身 SHA 改变属于预期。
