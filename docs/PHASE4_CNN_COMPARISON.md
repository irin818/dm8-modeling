# 第四阶段：紧凑卷积网络与可解释像素模型对比（2026-09-29）

## 问题与结论

此前单像素模型对部分 ROI 有可复现的预测，但五次记录的全体 ROI 测试 R² 中位数均为负。其输入只有一个训练段选出的位置和该位置的 18 次刺激历史，可能遗漏邻近位置或非线性关系。因此增加一个能看见完整 15×15 图案的小型卷积网络，测试这种额外表达能力是否能提高预测。

**结果：没有稳定提高。**五次记录中，CNN 的测试 R² 中位数没有形成一致增益；fly3 明显变差。以 ΔR² > 0.01 作为有实际幅度的改善，236 个 ROI 中只有 4 个达到，75 个下降超过 0.01，其余变化小于等于 0.01。此阈值仅用于描述变化幅度，不是显著性检验。毕业设计应保留原像素模型作为主要可解释模型，将 CNN 作为复杂模型对照，并展示负结果。

## 数据、模型与对比方式

每次记录均使用保存的 9,000×15×15 二值刺激及同步的 ROI 原始平均强度。五次记录共 236 个 ROI。CNN 和像素模型共享相同的 TTL 对齐、当前及过去 17 次刺激更新、训练/验证/测试帧、两处 18 成像帧的间隔、以及测试 R² 定义。测试段的响应不参与训练和轮次选择。代码复用原像素模型的训练期所选位置与验证期所选 Ridge 惩罚，且对输入文件哈希、ROI 名称和测试段逐项核对。

网络结构为：`18×15×15 刺激历史 → 两层 3×3 卷积（每层 4 通道）→ ELU → 平均池化 → 16 单元非线性层 → 每个 ROI 的修正值`。输出再加上**固定**的已保存单像素线性预测。这个残差结构保留了原模型的空间位置与时间权重解释；CNN 只尝试解释其遗漏的部分。依 ROI 数量，每次记录约有 4,666–4,802 个可训练参数。

训练期用每个 ROI 的均值和标准差缩放响应。网络先在训练段拟合，以整个验证段的平均标准化均方误差选择训练轮次（最多 60 轮，连续 10 轮未改善提前停止）。然后从相同随机种子重新初始化，用训练加验证段拟合所选轮次，最后只在后段测试一次。第 0 轮表示验证认为原像素模型已优于任何尝试的 CNN 修正，此时正式评分直接沿用原模型预测。随机种子、超参数、所选轮次、验证曲线、原始输入哈希和逐 ROI 分数均保存到输出目录。

## 同一后段测试的结果

| 记录 | ROI 数 | 所选轮次 | 原像素模型 R² 中位数 | CNN R² 中位数 | ΔR² > 0.01 | ΔR² < −0.01 |
|---|---:|---:|---:|---:|---:|---:|
| fly1 | 42 | 2 | −0.196 | −0.199 | 0 | 10 |
| fly2 | 50 | 0 | −2.240 | −2.240 | 0 | 0 |
| fly3 | 50 | 13 | −0.275 | −0.415 | 0 | 46 |
| fly4 | 48 | 2 | −0.118 | −0.117 | 0 | 0 |
| fly5 | 46 | 4 | −0.019 | −0.029 | 4 | 19 |

三例适合和原有讲解图配合：fly1/Mean29 从 R² 0.23529 到 0.23501，几乎没有变化；fly4/Mean34 约 0.11511 到 0.11511；fly5/Mean36 从 0.15562 到 0.15902，增益约 0.0034，也低于上表的 0.01 描述阈值。这些示例仍以**原像素位置、18 个时间权重及刺激独立预测**作为解释重点。网络增加的空间/非线性修正没有证明更好。

fly3 是有用的诊断例子：验证段平均标准化误差从约 1.293 降到 1.269，但后段测试 R² 中位数从 −0.275 降到 −0.415。说明在这一记录上，更灵活的修正即使改善验证段，也没有稳定迁移到晚期。不能由此单独判定原因是网络过拟合、记录漂移或生理变化；这些机制需额外证据。

## 为什么原先结果弱，为什么 CNN 没解决

当前目标是 `Results.csv` 的**原始 ROI 平均强度**，不是已经去背景、运动校正并验证的钙活动量。先前共同 ROI 对照已显示某些通道含有同一时间的共享强度波动；该信号不在视觉图案输入中，单靠扩大视觉模型不能保证预测它。单像素模型还可能遗漏多位置输入；本次 CNN 正是对这一点的检验，但未观察到总体改进。因此“缺少空间非线性容量”不足以解释全体弱分数。不同时间段的信号分布变化也是一个可能因素，fly3 的验证/测试差异支持谨慎对待这一点，但不足以确定具体原因。

负 R² 表示模型在相应 ROI 的后段测试中比“用该测试段自身均值预测”的数学参照还差；不代表实验没有视觉响应，也不等于代码未运行。少数 ROI 的正成绩与多数 ROI 的弱成绩应同时展示。

```bash

  --model-file outputs/cnn_comparison/fly1/20260619_105040/cnn_model.pt \

```

每次记录的 `cnn_metrics.json` 是完整评测与设置，`cnn_model.pt` 是保存的权重和归一化参数，`cnn_test_predictions.npz` 保存原模型、CNN 与实测值在同一测试帧上的配对数组。根目录 `summary.json` 是五次记录的概览。独立预测命令只用刺激历史和已保存 CNN 参数重算预测，再用实测值评分；它也核对保存的预测、时间戳和原始输入哈希。所有产物在 Git 忽略的 `outputs/`，实验原件未修改。PyTorch 是仅运行深度比较时需要的可选依赖。

## 答辩建议及边界

可先展示单像素模型的“位置—时间权重—预测曲线”，再用上表说明：引入能看到整幅图案和非线性的网络，并没有让全体测试成绩变好。这使模型选择有实证依据，也避免把网络复杂度当成研究成果。项目不引入基因型参数，也不要求新增记录。

五次记录共用同一冻结随机刺激；这些测试是每次记录内部的晚期时间段，不是新随机刺激或独立批次的泛化。模型家族在此前分析中已经接触过旧测试结果，本阶段对比应称为现有数据上的**探索性时间分段比较**，不应包装成完全盲测。目录名 `UV-15Hz` 不是波长或辐照度测量，现有输入也不支持光谱机制结论。
