# 第二阶段：首个可核验、可解释的局部刺激预测模型（2026-09-29）

> 毕设采用现有记录作为 Dm8 数据集，模型目标为 ROI 原始平均强度；不以基因型、新记录或光谱校准作为毕设完成条件。最终展示路径见 `GRADUATION_DESIGN_GUIDE.md`。

## 结论

已完成并运行一个 15×15 冻结刺激中的**单像素、18 个历史更新的线性时间滤波器**。它能在部分 ROI 的后段记录中预测原始平均荧光强度，且位置和时间权重可直接检查。五次记录的 236 个 ROI 中，模型对多数 ROI 无有效预测；因此不能将局部正结果外推为所有 Dm8 细胞的通用模型，也不能把原始强度称为已核验的钙响应。

示例 fly1/Mean29：训练段选择所存矩阵的第 9 行、第 7 列（从零开始），验证段独立估计的最佳像素相同。验证 R² = 0.130；后段测试有 2,413 帧，Pearson r = 0.493，R² = 0.235，而训练加验证均值常数预测的测试 R² = −0.001。测试前、后两半的 R² 分别为 0.207、0.228。对固定测试预测做全部允许的循环时间错位对照，双侧 p = 0.000425；对五次记录的全部 236 个 ROI 做 Benjamini–Hochberg 校正后 q = 0.00162。按 68 帧连续块做 2,000 次配对 bootstrap，r 的 95% 区间为 0.426–0.542，R² 区间为 0.159–0.272。该区间只量化同一测试时段内采样波动，不包括实验批次或模型家族选择的不确定性。

## 模型与防泄漏设计

对成像帧 `t`，先用同一 Due 微秒时钟找到该时刻之前最近的刺激更新 `u(t)`。模型只使用选定像素 `p` 在 `u(t), u(t)-1, …, u(t)-17` 的历史值：

```text
predicted_raw_ROI_mean(t) = intercept + sum_l coefficient[l] * stimulus[u(t)-l, p]
```

选择像素时，仅使用最早 50% 可用帧，对 225 个位置各算 18 个滞后项的训练期协方差，再选平方和最大的一个。隔开 18 个成像帧后，用约 20% 的验证段，在每个 ROI 内从 `0.001, 0.01, 0.1, 1, 10` 选择 Ridge 惩罚。随后用训练加验证帧重拟合，仍排除第一段间隔。第二个 18 帧间隔之后的约 30% 帧只用于测试。Ridge 的惩罚为 `λ × 拟合帧数 × 系数平方和`，截距不惩罚。所有原始输入文件只读；软件输出包含每次运行的输入 SHA-256、时间边界、逐 ROI 指标、系数和测试预测。

对照检验将**固定的测试预测**相对于测试目标循环平移，排除前后各 30 成像帧的近零位移，然后计算与零位移同样大的绝对相关出现比例。该方法保留序列的自相关结构，是时间配对对照，不是新实验的重复测量，也不能排除非平稳漂移的所有影响。FDR 的 236 个检验是每个 ROI 一次，未覆盖我们在本次研究中先前探索的其他模型家族。

## 五次记录的完整覆盖

| 记录 | ROI 数 | 测试 R² 中位数 | R² > 0 的 ROI |
|---|---:|---:|---:|
| fly1 | 42 | −0.196 | 8 |
| fly2 | 50 | −2.240 | 3 |
| fly3 | 50 | −0.275 | 1 |
| fly4 | 48 | −0.118 | 8 |
| fly5 | 46 | −0.019 | 14 |

全部 236 个 ROI 中，有 13 个验证 R² 高于 0.05，其中 10 个测试 R² 为正。这一 0.05 门槛只作描述，不用于挑选模型或计算显著性。另有 31 个 ROI 同时达到测试 R² > 0 与时间错位 q < 0.05；显著相关并不等同于良好的强度标定，例如 fly2/Mean35 验证 R² = 0.158、测试 r = 0.347，但测试 R² = −1.672。五次记录都使用同一个冻结刺激序列，不能将这些数字理解为面对新刺激种子时的泛化。

其他可核验的局部例子包括 fly4/Mean34：训练和验证均选第 7 行、第 7 列，测试 r = 0.346、R² = 0.115；fly5/Mean36：同一存储像素位置，测试 r = 0.411、R² = 0.156。选中位置是 `stim_realized.npz` 所存矩阵坐标，并未通过投影光路确认视网膜方向或角度。上述 ROI 的原始强度无零值；各会话的所有 ROI 合计零值比例为 0.5%–3.1%，其含义仍需查看 ROI 提取流程。

## 可以解释什么

fly1/Mean29 的 18 个权重均为负，最大绝对值在当前更新后约 1–2 个 15 Hz 更新的滞后处，随后逐步衰减。这意味着，在当前文件编码与时间对齐下，该位置从 −1 转到 +1 往往对应后续记录强度降低。第三阶段已核验数字命令中 −1/+1 对应灰度 0/100，但实际光谱和辐照度仍未核对，不应直接称为“UV 抑制”或“暗刺激兴奋”。Zeiss frame-out TTL 是曝光时间代理，因此约 67–133 ms 的权重峰值也不是精确神经延迟。

该模型符合原先“先单条件、先时空基线、再验证可解释模型”的路线。阶段一的全空间 STA 与 binned Ridge 在多数 ROI 上较弱；局部模型揭示了部分 ROI 的稳定空间位置和时间过程。它仍是预测性统计模型，无法独自证明 pDm8/yDm8、色彩选择性、受体输入或生物机制。

## 可信度边界

本模型的算法选择是在已看过同一后段数据的早期探索之后形成的。因此虽然程序内部严格分开训练、验证、测试，**当前测试不是完全未触及的最终确认集**。毕设中应如实报告为“现有数据上的时间分段验证”。新刺激序列是未来科学扩展，不是本次交付前提。

当前可交付的是单条件、数字灰度刺激到 Dm8 ROI 原始平均强度的可解释预测模型。第三阶段已核验数字亮度映射和标称网格几何。物理光谱、ΔF/F 重算和细胞机制属于可扩展方向，当前模型不对这些量作推断。

## 复现

在仓库根目录：

```bash
.venv/bin/python -m pip install -e .
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/dm8-model --data-root /Users/irin/Documents/Dm8_module --model pixel --output-dir outputs/pixel_raw
.venv/bin/python scripts/validate_pixel_model.py --results-dir outputs/pixel_raw
```

逐 ROI 数值在 `outputs/pixel_raw/fly*/<run>/pixel_metrics.json`，系数和测试预测在同目录 `pixel_model.npz`；汇总和配对块 bootstrap 在 `outputs/pixel_raw/validation.json`；示例矢量图在 `outputs/pixel_raw/example_pixel_model.svg`。生成目录被 Git 忽略，不修改原实验文件。所需第三方依赖只有 NumPy。
